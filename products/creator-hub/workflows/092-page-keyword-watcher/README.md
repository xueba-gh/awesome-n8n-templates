# Page keyword watcher (alert when text appears or disappears)

Watches a page for a phrase. With the defaults it alerts you when the phrase 'In stock' is missing; flip one setting to alert when a phrase appears.

## What you need

- Gmail

## Setup

1. Open **Settings** and list the addresses to check (and your email). Set **keyword** and **alert_when_found** (true = alert when the phrase appears, false = alert when it is missing).
2. Connect Gmail on **Email me the alert**.
3. Run it once by hand, look at **Judge the result** to see what it found, then switch to **Active**.
4. It only emails you when something is wrong, so a quiet inbox means all is well.
