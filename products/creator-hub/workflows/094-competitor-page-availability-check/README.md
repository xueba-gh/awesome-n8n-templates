# Booking page availability watcher (appointment slots)

Checks a booking page and alerts you when the 'No availability' message goes away, so you can grab a slot.

## What you need

- Gmail

## Setup

1. Open **Settings** and list the addresses to check (and your email). Set **keyword** to the sold-out wording on the page.
2. Connect Gmail on **Email me the alert**.
3. Run it once by hand, look at **Judge the result** to see what it found, then switch to **Active**.
4. It only emails you when something is wrong, so a quiet inbox means all is well.
