# Duplicate finder for a Google Sheet (weekly report)

Weekly check of a contacts or leads sheet for duplicate rows (by email, or any columns you choose) and an email listing them. Never deletes anything.

## What you need

- Google Sheets
- Gmail

## Setup

1. Open **Settings**: sheet URL, tab name, the column(s) to match on (for example `email`, or `name` + `phone`), your email.
2. Connect Google Sheets and Gmail.
3. Run once by hand. It only reports and never deletes rows.
4. Switch to **Active** for a weekly check.
