# Weekly newsletter drafter from your favourite RSS feeds

Collects this week's posts from the feeds you follow and emails you a ready-to-edit newsletter draft with an intro and short write-ups.

## What you need

- Gmail
- OpenAI API key

## Setup

1. Open **Settings** and list your RSS feed URLs (most blogs have `/feed` or `/rss`; a YouTube channel is `https://www.youtube.com/feeds/videos.xml?channel_id=...`).
2. Connect Gmail and OpenAI on the nodes with warnings.
3. Run it once by hand and look at **Keep new items**, then switch to **Active**.

## About this template

Built and checked by a new n8n creator. It uses standard n8n nodes only, has no credentials inside, and every setting you need to change sits in the **Settings** node. Test with dummy data first.
