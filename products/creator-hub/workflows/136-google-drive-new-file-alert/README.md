# New file in a Google Drive folder: email alert to the team

When a client or colleague drops a file in a shared Drive folder, your team gets an email with the file name and link.

## What you need

- Gmail
- Google Drive

## Setup

1. Open **New file in folder** and paste the folder URL (or pick it from the list).
2. Open **Settings**: who gets the email and a friendly folder name.
3. Connect Google Drive and Gmail.
4. Drop a test file in the folder, then switch to **Active**.
